# External references

This page links the Microsoft pages for the destinations that AppPackager uses.

## What it does

It points to the product documentation behind each destination.

## When to use it

Use it when you need the background of a right, a service or a setting.

## Requirements

None.

## Steps

None.

## Options and settings of this page

| Topic | Microsoft Learn |
|---|---|
| Create applications in Configuration Manager | [Create applications](https://learn.microsoft.com/intune/configmgr/apps/deploy-use/create-applications) |
| Configuration Manager console module | [ConfigurationManager module](https://learn.microsoft.com/powershell/module/configurationmanager/) |
| Intune Win32 apps | [Win32 app management](https://learn.microsoft.com/intune/intune-service/apps/apps-win32-app-management) |
| Microsoft Graph, Intune apps | [mobileApp resource type](https://learn.microsoft.com/graph/api/resources/intune-apps-mobileapp) |
| Locally published WSUS updates | [WSUS API, locally published updates](https://learn.microsoft.com/windows/win32/api/_wsus/) |
| Hardware inventory | [Configure hardware inventory](https://learn.microsoft.com/intune/configmgr/core/clients/manage/inventory/configure-hardware-inventory) |

## Limits

The links point to pages that Microsoft owns. A page can move.
