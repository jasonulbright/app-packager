# Glossary

This page defines the terms of AppPackager.

## What it does

It gives one short definition for each term that the tool and this guide use.

## When to use it

Use it when a term is not clear.

## Requirements

None.

## Steps

None.

## Options and settings of this page

| Term | Meaning |
|---|---|
| Packager | The script `package-<app>.ps1` of one application. |
| Stage | The phase that builds the content in the download root. |
| Package | The phase that publishes the staged content to a destination. |
| Manifest | `stage-manifest.json`. It describes the staged application. |
| Download Root | The local folder of Stage. |
| File Share Root | The content share of Configuration Manager. |
| Destination | ConfigMgr, Intune or WSUS. |
| One Click | The unattended run of the tracked applications. |
| Profile | A named set of Workbench changes for one application. |
| CPE | The name that NVD uses for a product. |
| KEV | The CISA catalog of Known Exploited Vulnerabilities. |
| EPSS | A score for the chance that a CVE is exploited. |
| ARP | Add/Remove Programs. |
| SMS Provider | The server role that gives access to the site data. |
